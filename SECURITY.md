# Security Policy

## Scope

Apartment Dashboard is a front-end-only demo. It has no backend, accounts or network API, and all data is fictional and stored in the visitor's own browser (`localStorage`). Still, if you find a vulnerability (for example in a dependency or the build/deploy workflows), please report it responsibly.

## Supported versions

Only the latest release on the `main` branch receives fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Use GitHub's private reporting instead: go to the **Security** tab of this repository and choose **Report a vulnerability**
([direct link](https://github.com/omarGH99/apartment-dashboard/security/advisories/new)).

Include a description, steps to reproduce and the potential impact. You can expect an initial response within a few days.
